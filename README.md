## Advanced Previewer Add-on for Anki 2.1

Hey everybody, this is a rewritten version of glutanimate's advanced_previewer for 2.1. The code is completly different for 2.1 so I'm not copy writting anything since it's it's own thing. After installation go to browser -> edit -> advanced previewer. 
<br>
The only thing is the next button goes to the next question and not the previous answer you need to "show answer" to show answer. 

<br>

Good luck, I'm not spending any more time on updating this, enjoy. 

<br> 

Some inspect files just tell us what each of the attributes does in pyqt6. 


### installation

git clone <this repo> 
<br>
restart anki
